About ClaimSense

ClaimSense is a first-decision co-pilot for auto-claim adjusters. For one claim it reads the claims, policy and document systems through a governed door, applies the policy manual with clause citations, and posts a recommendation. A licensed human confirms every outcome; ClaimSense never moves money (CLS-PAY-012).

Live mode

By default the portal shows recommendations computed when it was built. To call a deployed ClaimSense API instead, enter its base URL (the API Gateway URL from deploy/). Requests send only the user id, claim id and an optional note.
